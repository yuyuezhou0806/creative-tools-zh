四款创作工具 · 中文便携合集

图片、视频、动效和 PDF 四个独立工作台。适用于 Windows 64 位 Intel / AMD 电脑，建议 Windows 10 / 11。

开始使用

  1. 把 ZIP 中的整个文件夹完整解压到可写的位置，例如桌面或文档目录。
  2. 在最外层选择对应的中文「启动…」入口并双击。
  3. 先保存文档或项目，再导出结果；使用文件副本可保留原始素材。

无需安装 Codex、Python 或 Rust。请使用本包最外层的中文启动入口，设置会保存在软件旁的数据目录；EffectCraft 的入口也负责启用该便携配置。

PhotoCraft · 图片编辑

启动图片编辑-PhotoCraft.cmd

打开图片 → 编辑图层、文字或调整 → 另存文档 → 导出 PNG / JPEG。

FilmCraft · 视频剪辑

启动视频剪辑-FilmCraft.cmd

新建项目 → 添加素材并放入时间轴 → 保存项目 → 导出视频。

EffectCraft · 动效制作

启动动效制作-EffectCraft.cmd

新建合成 → 添加图层、关键帧和效果 → 保存项目 → 导出预览。

PdfCraft · PDF 处理

启动PDF处理-PdfCraft.cmd

打开 PDF → 从「所有工具」选择操作 → 保存为新的 PDF → 检查结果。

中文显示与使用范围

默认简体中文，部分专业名称和诊断文字可能保留英文。中文界面使用收件电脑的系统中文字体；若出现方框字，请安装 Windows 简体中文语言 / 补充字体后重新启动。

PhotoCraft 使用官方程序，另外三款使用本机中文构建。此包为非官方整理版本；具体格式和功能兼容范围需按实际文件检查。

各目录还包含对应命令行程序，可供后续自动化连接。工具信息、开源许可、资源归属及本地修改说明均已随包提供。
